Weight-space programming, with your agent at the controls

Let an AI agent read, probe and edit neural-network weights directly, with no gradient descent: every forward pass budgeted, every edit a reviewable patch, and held-out data it never sees. You watch and approve here.

1Connect an agent

Add the MCP server to Claude Code (or any MCP client): 
claude mcp add wsp -- wsp mcp --budget 50

2Give it a challenge

Five auto-scored tasks, from "find the induction heads" to "fix a model without running it". See challenges → 
wsp challenge prompt fix-the-copier --model claude-fable-5-2

3Watch and review

Each session's log updates live. Patches wait here for your approval before anything can be exported. 
wsp agent run fix-the-copier --model claude-fable-5-2
