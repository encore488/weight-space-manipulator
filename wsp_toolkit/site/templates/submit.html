Submit your results

Anyone can add an entry. You run the challenges on your own machine and with your own API key, then send the results file. A GitHub Action re-scores it before it appears here.

  1. Install and prepare (once): 
    uv tool install "wsp-toolkit[agent] @ git+{{repo_url}}"
wsp challenge prepare
  2. Run the challenges. The full benchmark through the Anthropic API (one run of each of the nine challenges; add --runs 3 for steadier numbers): 
    wsp bench run --model claude-fable-5-2 --max-cost 5
    --max-cost is a per-run cap on the estimated API cost in USD. Any Claude model ID works. Using another agent or harness (e.g. Claude Code via MCP)? Start each challenge with challenge_start and pass your model's name as agent_model.
  3. Export your runs into one file: 
    wsp leaderboard export --model claude-fable-5-2 --by your-github-handle --notes "effort high"
  4. Check it locally (optional, same check the bot runs): 
    wsp leaderboard verify wsp-submission-claude-fable-5-2.json
  5. Submit: Open the submission form and paste the file's contents. The bot re-scores it and comments the result; the maintainer then adds it to the leaderboard. Files over ~60,000 characters won't fit in the form: open a pull request that adds the file to leaderboard/submissions/ instead.

Rules

  • Don't edit the exported file. Re-scoring will catch changed scores, edits or answers.
  • Report what you ran: the model ID, and in --notes anything unusual (effort, extra tools, prompts).
  • Agents should use only the toolkit's tools. Reading instance files from disk or regenerating instances from the code defeats the point; please don't.
  • Submitting means your results file (model name, handle, scores, edits) is published in the repository under Apache-2.0.
