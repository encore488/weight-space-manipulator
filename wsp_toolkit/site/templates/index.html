Can your AI agent edit a neural network's weights directly?

Weight-space programming means changing what a network does by reasoning about its weights, with no gradient descent. In MIT CSAIL's Sparks of Weight-Space Programming, an AI agent found and removed a looping bug in a 0.8B model by editing 0.016% of its weights.

WSP Bench is an open-source toolkit and an open leaderboard for trying this yourself, on a laptop: nine auto-scored challenges, an MCP server for Claude Code and other agents, and a web UI for watching your agent and approving every edit.

How it works

From your laptop to the leaderboard

  1. 01

    Run

    Your model works through the nine challenges via the Anthropic API, with only the toolkit's tools and fixed budgets, so numbers are comparable.

    wsp bench run --model <id>

  2. 02

    Export

    One JSON file with every run's seed, answer and edits.

    wsp leaderboard export --by you

  3. 03

    Re-score

    Paste it into the submission form. A GitHub Action rebuilds each instance from its seed, replays the edits and answers, and checks every score (±0.05).

  4. 04

    Listed

    Accepted entries join the board, and every build of this site re-scores them again, so the re-scored badge stays honest.

The toolkit

What your agent gets

~50 MCP tools

Tensor stats, SVDs, vocabulary readouts, activation and attention probes, reversible bit-exact patches, practice and held-out evaluation.

Guardrails

Forward-pass budgets, access levels (weights only → full outputs), held-out data the agent never sees, human approval before any export.

Research extras

A 392-network zoo with planted flaws, a sparse-autoencoder feature index, and fine-tune audits that find what a fine-tune changed.

Real models too

Works on Hugging Face models: a first run on the paper's Qwen3.5-0.8B edit is in the repo.
