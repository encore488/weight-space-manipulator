Can your AI agent edit a neural network's weights directly?

Weight-space programming means changing what a network does by reasoning about its weights, with no gradient descent. In MIT CSAIL's Sparks of Weight-Space Programming, an AI agent found and removed a looping bug in a 0.8B model by editing 0.016% of its weights.

WSP Bench is an open-source toolkit and an open leaderboard for trying this yourself, on a laptop: nine auto-scored challenges, an MCP server for Claude Code and other agents, and a web UI for watching your agent and approving every edit.

Try it

1Install

Python 3.11+, CPU is enough. With uv (after installing it, open a new terminal): 
uv tool install "wsp-toolkit[agent] @ git+{{repo_url}}"
wsp challenge prepare

2Run the benchmark

Through the Anthropic API, where the model gets only the toolkit's tools (comparable numbers): 
export ANTHROPIC_API_KEY=...
wsp bench run --model claude-fable-5-2
or one challenge: wsp agent run fix-the-copier --model …

3Submit

Export your runs and paste the file into the submission form. A bot re-scores it before it joins the leaderboard. 
wsp leaderboard export --model claude-fable-5-2 --by your-handle
How submitting works →

Prefer to watch an agent work? claude mcp add wsp -- wsp mcp --challenge fix-the-copier, then wsp challenge prompt fix-the-copier and wsp ui. Connecting agents →

What's in the toolkit

  • ~50 MCP tools: tensor stats, SVDs, vocabulary readouts, activation and attention probes, reversible bit-exact patches, practice and held-out evaluation.
  • Guardrails: forward-pass budgets, access levels (weights only → full outputs), held-out data the agent never sees, human approval before any export.
  • Research extras: a 392-network zoo with planted flaws, a sparse-autoencoder feature index, and fine-tune audits that find what a fine-tune changed.
  • Also works on Hugging Face models: a first run on the paper's Qwen3.5-0.8B edit is in the repo.
