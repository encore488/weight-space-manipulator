    Run a challenge

    wsp agent run fix-the-copier --model claude-fable-5-2
  2. 02

    Watch it live

    The arena follows the newest run as it happens. The model's thinking summaries appear as captions.

    wsp ui   # then open /arena

    Record in the browser

    Press ● Rec in the arena to save a WebM in real time. Pick 16:9, 1:1, 4:5 or 9:16 first.

    Frame-exact H.264 via headless Chromium:

    pip install "wsp-toolkit[video]" && playwright install chromium
