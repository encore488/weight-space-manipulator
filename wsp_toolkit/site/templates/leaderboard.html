What the columns mean

re-scored

This site's build rebuilt every run's instance from its seed, replayed the submitted edits and answers, and got the same score (within ±0.05; instances are small trained models and differ slightly across platforms).

Harness

wsp-agent-runner means the model got only the toolkit's tools through the Anthropic API. mcp (self-reported) means an MCP client such as Claude Code, which may also have had shell access. unlocked means the server wasn't locked to the challenge.

What re-scoring can't check

Which model produced the run, and whether budgets were respected. Those come from the submitter's own log. Treat entries as honest self-reports whose scores are reproducible.

The reference entry

{{baseline}} is deterministic code using the same tools: a reference point, not an AI.
